# Mag Life — 日常に、余白と出会いを。

React + Vite + TypeScript で動く、雑誌の視点で空き時間にお出かけを提案する日本語のカレンダーデモです。

## セットアップ

Node.js 24 を推奨します（アプリ本体は20.19以降の20系、または22.12以降でビルド可能。`npm test` はTypeScriptを直接実行できるNode.js 22.18以降が必要です）。

```sh
npm ci
npm run dev
```

http://localhost:5173/magazine-linked-calendar-app/ を開いてください。

## できること

- **カレンダー**：日・週・月の切り替え、前後移動、今日への復帰、日付選択、予定の追加・編集・削除。初期状態には仕事・プライベート・雑誌からのお出かけのデモ予定が入っています。
- **カラフルな予定**：カレンダーの土台は白。雑誌のお出かけ予定はビビッドなピンク・ライム・パープル・ミント・オレンジ・シアンで表示します。
- **空き時間提案**：選択日の09:00–22:00にある45分以上の空き時間を検出。記事の所要時間とデモ営業時間に合う提案だけを表示します。仕事終わりや金曜の夜にはメッセージも変わります。
- **操作できるカード**：記事を開く、お気に入り保存、パス、予定に追加。右スワイプ・マウスドラッグで追加、左でパス。ボタンでも同じ操作ができます。
- **記事・スポット**：15件のオリジナルの架空記事を写真付きで収録。「見つける」ではグルメ・カルチャー・自然で絞り込めます。
- **一日プラン**：11:00カフェ → 13:00ギャラリー → 15:30ショッピング → 18:00ディナー。各スポットから記事を開けます。日付を選び、4件をまとめて追加できます。
- **広告**：Sponsored Recommendation / Calendar Native Ads / Editorial Sponsored Story を収録。カード・記事・追加された広告の予定にもPRを明示。読むだけでは予定に追加されません。
- **モーション**：カードの表示・タップ・ドラッグ、お気に入り、広告バナーのホバーに対応。`prefers-reduced-motion` に従い動きを抑制します。

## 保存・予定の重複

予定とお気に入りを、このブラウザの `localStorage`（`mag-life-v1`）に保存します。同じブラウザ・同じオリジンで再度開くと復元されます。外部送信・アカウント認証・端末間同期はありません。保存失敗や不正な保存データは画面に通知します。

追加・編集時には時間の重複を確認します。一日プランは既存予定と重なる、または同じスポットが登録済みの場合、**1件も追加せず**日付の変更・予定の調整を案内します。空き時間への追加後は提案を再計算します。

起動時にデモ予定を前後約7週間分生成します。予定のない日も自由に追加できます。ブラウザのサイトデータを消去するとデモ初期状態に戻ります。

## 検証

```sh
npm run lint
npm test
npm run build
npm run preview -- --host 0.0.0.0
```

`build` は TypeScript の型チェックと `dist/` への本番ビルドです。ドメインテストでは空き時間の45分境界・重複・日付境界・営業時間・デモデータ・一日プラン・保存失敗を確認します。

## GitHub Pages

公開先： https://otoufutarou.github.io/magazine-linked-calendar-app/

Vite の `base` は `/magazine-linked-calendar-app/`。画像も `import.meta.env.BASE_URL` から参照し、サブパスに対応します。画面はアプリ内の状態で切り替わるため、サーバーのルート設定やSPA用404ページは不要です。画像・記事は同梱しており、外部API・外部フォントサービスなしで動作します。

PRでは **Check Mag Life** がlint・テスト・ビルドを実行します。`main` へのマージ後は **Deploy to GitHub Pages** が同じ検証を行い、成功した `dist/` を公開します。Settings → Pages → Source は **GitHub Actions** を選択してください。

## デモの範囲・素材

ユーザー・雑誌名・記事・スポット・広告案件はすべて架空です。記事本文はオリジナルで、実在の記事の転載はありません。予約・購入・実際の広告配信・実店舗への送客は行いません。位置情報・交通経路・祝日・リアルタイムの営業時間には連動していません。所要時間は移動を含むデモ目安であり、実際の移動可能性を保証しません。

写真は店舗・展示を表すイメージです。一部は複数の記事で共用しています。同梱した写真の出典とライセンス表記は `public/images/THIRD-PARTY-NOTICES.txt` を参照してください。
